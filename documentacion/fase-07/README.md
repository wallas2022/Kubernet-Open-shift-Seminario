# Guía de exposición y demostración

La guía principal es DOC-07-02: [Word](word/DOC-07-02-guia-seis-grupos.docx) y [Markdown](fuentes/DOC-07-02-guia-seis-grupos.md).

Define los seis grupos, sus bloques de presentación, una agenda adaptable de tres horas y una demostración conjunta de 25 minutos del sistema de reservas. Incluye preparación, registro de cupos y comprobante, consulta, salida, evidencia de idempotencia y criterios de evaluación propuestos.

Se utiliza un laboratorio exclusivo para la demostración. Las reservas nuevas no se crean sobre la base medida de S19. Los manuales previos se conservan como apoyo técnico.

Consultar [investigación](../fase-01/README.md) y [presentación](../../presentacion/fase-06/README.md). Entrega local para revisión, sin commit ni push.

El montaje del escenario Kubernetes para evaluar hasta 50 000 usuarios y continuidad ante fallos tiene una [guía técnica y prompts propios en Fase 02](../fase-02/README.md). La guía funcional DOC-07-02 no sustituye ese proceso de construcción.
