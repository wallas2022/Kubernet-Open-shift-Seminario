# Instrucciones para entregar el trabajo a otro agente

Para un agente que construirá el laboratorio completo, abrir [00-prompt-maestro.md](00-prompt-maestro.md) y copiar su contenido al iniciar la sesión. Darle acceso al repositorio y pedir que comience por L00. El prompt remite al contrato común y a la guía técnica; no contiene credenciales.

Para repartir tareas por grupo, entregar [01-contrato-comun.md](01-contrato-comun.md), el prompt correspondiente y la [guía](../../fuentes/DOC-02-02-guia-laboratorio-ha-50000.md). Los prompts son autosuficientes en cuanto al objetivo, pero requieren lectura de esos archivos y acceso a las fuentes reales.

| Grupo | Prompt | Dependencias |
|---|---|---|
| 1 | [Arquitectura](02-grupo-1-arquitectura.md) | Inventario y decisiones L00 |
| 2 | [Autoescalado](03-grupo-2-autoescalado.md) | G1, presupuesto G4 y señales G5 |
| 3 | [Resiliencia](04-grupo-3-resiliencia.md) | Plataforma, datos y observación estables |
| 4 | [Datos](05-grupo-4-datos.md) | Plataforma y almacenamiento |
| 5 | [Observabilidad](06-grupo-5-observabilidad.md) | Topología y contratos de aplicación |
| 6 | [Experimentos](07-grupo-6-experimentos.md) | Integración de los cinco anteriores |

Las etapas son una secuencia con puntos de verificación, no instrucciones para que todos modifiquen los mismos archivos a la vez. Esta entrega prepara el trabajo; todavía no ejecuta el despliegue ni demuestra 50 000 usuarios.
